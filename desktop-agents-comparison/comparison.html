Camera bodies

Both use one CFexpress Type B slot and one UHS-II SD slot.

Supported memory cards

Choose fast CFexpress Type B for RAW/8K/high-burst work; use UHS-II SD for backup and lower-bitrate workflows.

Batteries

R5 Mark II is optimized for LP-E6P. Older LP-E6NH/LP-E6N can work with limitations.
